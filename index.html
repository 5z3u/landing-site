关于

我习惯把想法尽快做成能访问的东西 —— 从写第一行 HTML 到让它挂在一个真实域名上。 比起复杂框架，我更偏爱纯静态：加载快、成本低、几乎不会挂。

目前所有站点都托管在 GitHub Pages 上，通过自定义域名统一入口。 项目保持开源，欢迎随手看看，也欢迎提 issue 交流。
